Anonymous telemetry: turn it on or off, or see exactly what it sends (on/off/status)

Usage: sectr telemetry <COMMAND>

Commands:
  on      Turn telemetry on, with a new install id
  off     Turn telemetry off and delete the install id
  status  Show whether telemetry is on, and exactly what it sends
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
