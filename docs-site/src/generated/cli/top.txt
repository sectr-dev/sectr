Host AI agents — starting locally

Usage: sectr <COMMAND>

Commands:
  auth       Store the platform key for cloud commands (login/whoami/logout)
  init       Scaffold a new agent project: framework, frontend and where-it-runs pickers (or --template / --frontend / --endpoint), file emission, `uv sync`, and a smoke inspect. `--endpoint` in an existing project adds the files to run it on your own compute provider. See `init --help`
  dev        Run the app locally end-to-end: SQLite journal, subprocess runner, gateway for clients. See `dev --help`
  send       Send a message / decide an approval through the running `sectr dev` gateway (a thin client — it never starts the engine)
  tail       Follow a session's journal (never stops until ctrl-c)
  deploy     Ship the project to a server: package → upload → the server builds and activates. With `[deploy] endpoint` in sectr.toml, register your own compute endpoint instead. See `deploy --help`
  secrets    Manage the app's server-side secrets (write-only: set/list/rm)
  telemetry  Anonymous telemetry: turn it on or off, or see exactly what it sends (on/off/status)
  help       Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version
