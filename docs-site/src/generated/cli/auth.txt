Store the platform key for cloud commands (login/whoami/logout)

Usage: sectr auth [OPTIONS] <COMMAND>

Commands:
  login   Sign in: opens the dashboard in your browser to approve the request (or pass --key / --with-key to store an API key instead)
  whoami  Print the stored identity (org + server) after re-validating
  logout  Forget the stored key (and revoke it, if the browser login made it)
  help    Print this message or the help of the given subcommand(s)

Options:
      --api <API>  The server base URL. Default: SECTR_API_URL, then the saved login's server, then the public endpoint
      --key <KEY>  Platform API key (`skp_…`). With `login`, stores that key instead of opening the browser
  -h, --help       Print help
