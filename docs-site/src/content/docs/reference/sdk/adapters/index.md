title: Framework adapters
description: sectr.adapters — one adapter per supported framework, each on its own page.
---

Each adapter serves an agent written with one framework as a Sectr agent.
Each has its own page, with its signature, behavior and limits:

- [OpenAI Agents SDK](/reference/sdk/adapters/openai-agents/), `sectr.adapters.openai_agents`
- [LangGraph](/reference/sdk/adapters/langgraph/), `sectr.adapters.langgraph`
- [Pydantic AI](/reference/sdk/adapters/pydantic-ai/), `sectr.adapters.pydantic_ai`

For which frameworks are supported and how to install each, see the
[support matrix](/guides/framework-adapters/#support-matrix).
